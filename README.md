# Welcome 😊
# This is a short list of topics discussed in the course materials, organized by week.

## WEEK_01 — Python fundamentals and workflow
- Python basics: variables, data types, and operators
- Control flow: if/else, loops
- Functions: definition, arguments, return values
- Basic I/O and text processing
- Debugging and development workflow

## WEEK_02 — Data structures, functions, file handling, and OOP
- Built-in data structures: lists, tuples, sets, dictionaries
- Advanced function usage: scope, higher-order functions
- File I/O and text processing
- Object-Oriented Programming: classes, objects, inheritance, methods
- Exception handling and modules

## WEEK_03 — Numerical computing and data processing
- NumPy fundamentals and array operations
- Pandas: Series, DataFrame, reading/writing CSV/JSON
- Data cleaning and preprocessing
- Grouping, aggregation, and merging datasets
- Visualization basics with Matplotlib and Seaborn

## WEEK_04 — Advanced data processing and visualization
- Advanced Pandas techniques and pipelines
- Feature engineering and basic model evaluation concepts
- Advanced visualization patterns and styling
- Working with real-world datasets and exploratory data analysis
